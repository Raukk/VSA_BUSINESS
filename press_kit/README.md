# Press Kit

CONCEPTS: PRESS_RELEASE|PUBLIC_RELATIONS|MARKETING_COPY|PRODUCT_LAUNCH

Assembly area for press-release material: release copy, boilerplate, fact sheets, quotes, images.

Files here are outward-facing copy. The repo Output style rule (DENSE|NO_FLUFF|...) does NOT apply in this folder — write in a natural press register. Accuracy rules still hold: every technical number cites its VSA_ASIC path, no rounding past 1%, no unsourced claims.
