# Press Kit

CONCEPTS: PRESS_RELEASE|PUBLIC_RELATIONS|MARKETING_COPY|PRODUCT_LAUNCH

Assembly area for press-release material: release copy, boilerplate, fact sheets, quotes, images.

Files here are outward-facing copy. The repo Output style rule (DENSE|NO_FLUFF|...) does NOT apply in this folder: write in a natural press register. Accuracy rules still hold: every technical number cites its VSA_ASIC path, no unsourced claims, no exaggeration. Presentational rounding to 1-2 significant figures is allowed (owner ruling 2026-08-18, `CLAUDE.md`): round against our own interest, keep the exact figure and its VSA_ASIC path in the fact sheet or a footnote, and never let the rounded form become a different claim. No em-dashes in any file here: an AI-slop tell (owner rule 2026-08-14); en-dash ranges are fine. Exception (owner 2026-08-14): where an external entity specifies the format (e.g. the AP press-release dateline), follow their convention exactly, em-dashes included.
